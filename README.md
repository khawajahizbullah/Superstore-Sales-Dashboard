# Superstore-Sales-Dashboard
The “Superstore Sales Dashboard” project is a comprehensive Power BI visualization challenge aimed at analyzing sales, profit, and customer performance across regions, categories, and time.Using the Global Superstore Dataset, we build an interactive dashboard that provides actionable insights for business decision-making — including KPIs, slicers, and visual storytelling.
This project demonstrates how to transform raw sales data into a professional business intelligence dashboard used by analysts, sales managers, and executives to track growth, identify opportunities, and uncover performance trends.
🎯 Objective
To build a fully interactive Power BI Dashboard showing:
•	📦 Sales & Profit KPIs
•	🗺️ Regional Performance
•	🕒 Time-Based Trends
•	🧩 Category & Subcategory Analysis
•	🧮 Profitability and Discount Insights
•	🎚️ Interactive Filters & Slicers for dynamic exploration
⚙️ Tools Used
•	Power BI Desktop
•	Dataset: Global Superstore CSV
•	Techniques: DAX Calculations, Data Modeling, Dashboard Design, and Visual Formatting
📈 Dashboard Deliverables
•	Dynamic and interactive Power BI report
•	KPIs for sales, profit, and performance
•	Time-based trend visualizations
•	Regional and category drill-downs
•	Executive-level overview and storytelling visuals
💡 Key Insights
•	📊 The West Region generates the highest total sales and profit margins.
•	🏷️ Office Supplies category has strong sales but lower margins due to discounts.
•	💰 Technology leads in profitability and average sales per order.
•	🕒 Seasonal spikes in sales are visible during Q4 of each year.
•	🔍 Profit margins vary significantly by customer segment, indicating potential optimization areas.
🎯 Learning Outcomes
•	Hands-on experience with Power BI data modeling
•	Understanding DAX calculations and measures
•	Visual storytelling using business KPIs
•	Dashboard design best practices
